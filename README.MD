# Proyecto: Guía de Supervivencia en Minecraft

## Descripción
Este sitio web fue desarrollado como trabajo práctico para Programación III. 
Presenta una guía básica para conocer y comenzar a jugar Minecraft, incluyendo materiales, herramientas y primeros pasos dentro del juego.

El sitio fue diseñado aplicando conceptos de desarrollo web responsive utilizando HTML y CSS.

## Contenido
- Página principal (index.html)
- Menú de navegación responsive
-Imágenes ilustrativas
-Video integrado
-Tabla de materiales y usos
-Tarjetas informativas
-Diseño adaptable para dispositivos móviles
- Formulario de contacto

## Tecnologías utilizadas
- HTML5
- CSS3
