# Proyecto: Guía de Supervivencia en Minecraft

## Descripción
Este sitio web fue desarrollado como trabajo práctico para Programación III. 
Presenta una guía básica para conocer y comenzar a jugar Minecraft, incluyendo materiales, herramientas y primeros pasos dentro del juego.

El sitio fue diseñado aplicando conceptos de desarrollo web responsive utilizando HTML , CSS y JavaScript.

## Contenido
- Página principal (`index.html`)
- Menú de navegación responsive
- Imágenes ilustrativas
- Video integrado
- Tabla de materiales y sus usos
- Tarjetas informativas
- Diseño adaptable para dispositivos móviles
- Formulario de contacto
- Buscador de consejos de supervivencia
- Lista dinámica de consejos
- Botón de consejo aleatorio

## Funcionalidades implementadas

- Diseño responsive para distintos dispositivos.
- Manipulación del DOM mediante JavaScript.
- Uso de arrays para almacenar consejos.
- Búsqueda de consejos por palabra clave.
- Generación de consejos aleatorios.
- Validación del formulario de contacto.
- Manejo de errores mediante `try...catch`.
- Eventos `click`, `input` y `submit`.
- Contador de caracteres en el mensaje del formulario.

## Tecnologías utilizadas
- HTML5
